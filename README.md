# 🍃 Naruto Complete Timeline

A beautiful vertical scrolling timeline that tells the entire story of the Naruto universe — from Kaguya’s arrival on Earth all the way to Naruto becoming the Seventh Hokage.

Inspired by the interactive storytelling style of [neal.fun](https://neal.fun).

---

### ✨ Features

- Vertical scrolling narrative timeline
- Tree trunk design with **carved years**
- Shurikens stuck into the tree at random positions
- Rotating shuriken markers for each event
- Photos hanging on threads with gentle swinging animation
- Background music (Sadness and Sorrow)
- Fully responsive and works offline
- Pure HTML + CSS (very light and simple)
